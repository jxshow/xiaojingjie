# 小鲸洁 · 磁盘清理助手

适用于 Windows 和 Python 3.11+。在本地浏览器中运行，启动后先读取已知缓存、安装包和系统管理位置。用户需要全盘排查时，可先用已安装的 storage-analyzer 做只读扫描，分析大小与归属，再把分析 JSON 交给本技能。

## 启动

从本技能所在位置运行脚本，使用当前任务下的专用工作目录保存地址和执行记录。启动时使用隐藏窗口或托管的后台进程，让本地服务在用户操作期间可用。

```powershell
python -B "<技能目录>\scripts\desk.py" --session-dir "<任务目录>\work\disk-review-session"
```

默认打开浏览器。无桌面启动时传 `--no-open`，然后把会话目录中 `address.txt` 的完整本机地址交给用户。地址片段是本轮访问凭据，只在本机使用。所有页面关闭后服务最多空闲 30 分钟。多次启动时使用不同的会话目录。

- 可选的 `--report "<分析 JSON>"` 接受 storage-analyzer 的分析结果。首页给占用排行标注原报告时间，工作台把 yellow/red 项作为复核建议。尺寸标为上次估算。导入报告中的目录或命令不能获得清除权限。
- 对用户明确要保留的位置，逐个追加 `--protect "<绝对路径>"`。父子路径重叠的候选一起锁定。技能目录可放本机专有的 `local-settings.json`，其中 `protected` 为绝对路径数组，每次真实扫描都会加载。分发技能时排除此文件。
- 需要演示时使用 `--sample`，在指定会话目录生成两个缓存目录与一个模拟安装包。样本模式仅操作这些临时文件。
- 中文目录都用原始绝对路径和引号。启动服务本身仅开始扫描。

## 决策与结果

首页先展示系统盘余量、各盘占用和本次缓存测量，再根据最大缓存候选及预计释放后的余量给出建议。没有历史排行时，使用本次已测候选生成排行，界面会注明范围。导入排行只供查阅，不参与可释放空间计算。

用户在清单右侧点勾或叉。谨慎项按类型提供暂存安装包、还原、打开目录、打开系统存储设置或保留。只有内置缓存规则可以清除文件。查看旧报告的建议时，先确认当前程序、依赖和数据归属。涉及微信资料、会话、游戏和模型时，保留用户指定的保护范围。

预览会列出选择的项目、路径、操作和预计缓存文件量。确认后进度球按实际完成或跳过的文件和操作计数。缓存执行前复查位置和文件身份，遇到占用、链接或内容变化跳过。安装包暂存到下载目录下的 `.disk-review-hold`，同盘暂存不释放容量，下次扫描可还原。

完成后读取会话目录的 `receipt-*.json` 或界面的执行记录。区分成功、跳过、成功清除的逻辑字节和卷可用空间的实际变化。用户只要求制作或试用技能时，在样本上验证写操作。
